# Chaohaoyue (超好約)

Website for **超好約**, a LINE appointment service for clinics in Taiwan: patients book, reschedule and cancel in the clinic's LINE official account, and the front desk manages appointments and messages on a computer.

Served by GitHub Pages at https://sona-orbit.github.io/chaohaoyue/

- Home, download, support, privacy and blog pages in Traditional Chinese
- Static HTML and CSS; this repository holds the generated pages only
- Published by Sona Orbit. Issues and pull requests are turned off.
