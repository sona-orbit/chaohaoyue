診所用 LINE 官方帳號接受線上預約：患者怎麼約、櫃檯怎麼確認

先講結論：在 LINE 上接受預約，重點不是讓機器人什麼都自己決定，而是把「哪些可以直接約好、哪些要診所先看過」分清楚。這篇照一筆約實際走過的順序，從患者那邊講到櫃檯這邊。

這篇是超好約的開發者寫的。超好約是我做的診所 LINE 約診服務，文中引用的回覆都是它現在實際會說的話（〔〕裡的內容依診所設定替換）。寫於 2026 年 11 月。

1. 患者這邊：一次只問一件事

患者在診所的 LINE 官方帳號裡約診：點選單上的「線上預約」，或直接打一句「我想約下週三下午洗牙」。句子裡已經有的條件（哪一天、哪個時段、哪位醫師、什麼項目）先收下來，缺哪一樣就只問那一樣。

時間選好之後，不會馬上成立。患者會先看到一張核對卡：

請確認預約內容：〔日期〕〔時間〕・〔醫師〕・〔項目〕

按了「確認預約」才算數。判斷看錯的時候，也會停在這一步。

如果患者那天已經有一筆同樣項目的約，它會先問清楚是「另外再約一筆」還是「改原本那筆的時間」，不自己猜。

2. 約好了，還是送出等診所確認

診所可以決定哪些項目線上直接約好、哪些要櫃檯先看過。兩種情況患者看到的話不一樣：

情況患者看到
直接成立的項目預約好了 ✅ 〔日期〕〔時間〕・〔醫師〕・〔項目〕
要診所確認的項目預約已經送出 📝 ……這個項目要診所確認後才算成立，可以按「查我的預約」看目前的狀態。

要確認的那種，櫃檯在預約介面按確認或婉拒。時間較長、要先評估的項目，適合設成要確認。

3. 改期、取消，診所可以決定要不要開放

改期與取消可以分開設定。沒有開放時，患者在 LINE 上問，會收到這樣的回覆：

目前線上沒有開放取消，請來電〔診所電話〕，櫃檯會幫您處理。

改期設成要診所確認的話，原本的時段會先保留，等診所確認後才改過去：

改期申請已經送出 📝 原本：〔舊日期〕〔舊時間〕（先幫您保留）想改為：〔日期〕〔時間〕・〔醫師〕

如果新的約已經成立、舊的卻沒取消成功，它不會說「改好了」，而是告訴患者舊的那筆沒取消成功，並通知櫃檯處理。

4. 線上預約的幾條界線

  • 只約本人。幫家人或朋友約，會轉給櫃檯處理；患者其實是自己要約的話，可以點「我本人要約」繼續。
  • 一次一位。想一起安排好幾個人，請櫃檯協助。
  • 可以約幾週內。線上可約的範圍由診所設定，更晚的日子請患者接近時再約，或請櫃檯安排。
  • 語言。目前看得懂中文和英文，其他語言會請患者聯絡櫃檯。

5. 櫃檯這邊：預約介面與訊息介面

櫃檯在電腦上用兩個畫面：

  • 預約介面：看一週的約診，確認或婉拒患者送來的約，也可以替患者約診。醫師的班表、看診項目、診所的電話與地址也在這裡設定。
  • 訊息介面：左邊是 LINE 官方帳號原本的聊天頁，右邊多一塊面板，顯示現在點開的是哪位患者、他有哪些約診。要自己回的時候按「接手」，超好約就不會跟著回。

患者要找櫃檯時，它會先回：

好的，已經通知櫃檯人員，上班時間通常〔幾〕分鐘內會回覆您……等候的時候，預約、查預約都可以照常使用。

休診時間則會告訴患者櫃檯什麼時候回覆，預約、查預約照樣可以用。下班後想約診的患者，不用等到隔天。

6. 開始前要準備什麼

  1. LINE 官方帳號：診所已經有的直接用，沒有的先申請。
  2. 跟我們聯絡：我們把官方帳號接上超好約，套用聊天畫面下方的選單。
  3. 連線程式：由我們到診所或遠端，在櫃檯的電腦上裝好並完成配對。
  4. 下載櫃檯用的程式，填好醫師、班表與看診項目。
  5. 告訴患者加診所的 LINE。

要先決定的設定：哪些項目要確認、改期與取消要不要開放、線上可以約幾週內、櫃檯通常幾分鐘內回覆。

費用要留意 LINE 本身的規則：LINE 主動發送訊息要算則數，由診所的 LINE 官方帳號方案負擔；患者先傳訊息、我們回覆的不算。超好約的費用請來信詢問：sona.orbit.hi@gmail.com。

7. 目前做不到的事

  • 診所確認、婉拒或改期之後，目前要由櫃檯在 LINE 上告訴患者；自動通知與看診前一天的提醒還在做。
  • 櫃檯用的程式目前有 Mac 版，Windows 版準備中。
  • 目前只做診所，接的管道只有 LINE。

患者打字時它怎麼判斷、什麼時候不回話，寫在另一篇〈診所的 LINE 約診機器人，什麼時候不該回話〉。完整的規則對照表在首頁。

8. 常見問題

患者要另外下載 App 嗎？

不用。患者在診所的 LINE 官方帳號裡約，不用另外裝 App，也不用另外註冊帳號。

每一個項目都會直接約好嗎？

不一定。診所可以把某些項目設成要先確認，患者送出後會看到「要診所確認後才算成立」，櫃檯在預約介面確認或婉拒。

可以不開放線上取消嗎？

可以。改期和取消可以分開設定，沒開放時患者在 LINE 上會收到請他來電的回覆，由櫃檯處理。

LINE 的訊息費用怎麼算？

LINE 主動發送訊息要算則數，由診所的 LINE 官方帳號方案負擔；患者先傳訊息、我們回覆的不算。
