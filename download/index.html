下載櫃檯用的程式

一個安裝檔，裝完有兩個畫面：預約介面與訊息介面。之後有新版，程式開起來時會提醒並帶你到這一頁。

Mac

macOS 14 以上。

準備中

Windows

Windows 10、11。

準備中

要先完成開通才連得上。連線程式由我們到診所或遠端安裝，不在這裡下載。還沒開通的診所請來信：sona.orbit.hi@gmail.com

裝好之後

  • 先開預約介面，在設定裡填醫師、班表、看診項目，以及診所的電話、地址與看診時間。
  • 再開訊息介面，用管理診所官方帳號的那個帳號登入 LINE。登入一次之後會記住。
